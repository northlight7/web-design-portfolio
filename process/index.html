Process notes

Measured,
then kept.

Six sites, one engine, and a process built around looking at the result instead of trusting the first pass.

These notes cover what is shared, what was measured, what was thrown away, and what changed after the first build.

Back to the work ↗

01 / Structure

One engine,
six directions.

The six share a small Three.js core and a common inner-page system. What changes is the art direction, not the plumbing.

The core handles the renderer, the scroll timeline, motion preferences, context loss, resize and teardown. Each project supplies its own scene, camera path, palette and type. That split keeps the behaviour consistent and makes a fix in one place apply everywhere.

The shared layer is also why the six feel related without looking the same: a landscape, a watch, a filmstrip, a turntable, a bloom and a house all move to the same rules.

02 / Method

Three runs,
then a median.

A single performance score on this machine is not a measurement. The first run of each site is a cold start and reads far worse than the second and third.

Every comparison uses the median of three mobile runs. Where a change looked like it might cost performance, the old and new builds were measured in the same session, back to back. If the spread between runs was larger than the effect, the change did not count as an improvement.

That rule killed two changes that looked reasonable on paper.

03 / Rejected

Two things
that did not survive.

Deferred module boot

Loading the 3D module after first paint looked like an easy win. It moved the work instead of removing it, and the main thread paid for it later.

The rule was simple: if the effect is smaller than the noise, keep the version that looks better.

04 / Passes

What the
passes changed.

  • 01

    ALTO

    The field atlas now draws its ascent profile from the same height field that builds the terrain. The drawing and the mountain cannot disagree, and the three routes share one source of truth.

  • 02

    MERIDIAN

    The case finishes turning at 70 percent of the pinned section instead of 88, so the movement holds on screen before the scene releases. The reverse of the strap gained a leather lining, grain and stitching where it had been a dark slab.

  • 03

    OVERTURE

    The saved-films band was rebuilt from a bordered box into an editorial rule with dark ticket stubs after the first pass read as a form rather than a programme.

  • 04

    Auralis

    The transport readout was added, and the reveal no longer dims the object it is revealing.

  • 05

    Nocturne

    The cap now rests inside the frame, and the headline clears the bottle instead of crossing it.

  • 06

    Monolith

    An accessibility pass only. The art direction was left alone because it was already carrying the idea.

05 / The quiet parts

The work that
does not show.

A scene that looks right at 1440 px is not finished. Every page was also checked at mobile width, with keyboard focus, and with motion turned off.

One label introduced during a late pass landed at 3.65:1 contrast. It was caught in the final check and fixed to full ink before release. The rest of the type was checked against the same rule.

The galleries are static. There is no login, no tracking script and no paid service. Each demo is buildless and can be served from any static file server, which also means there is no server to fall over.

What this is not.

The six are independent concept projects. There are no clients, no commercial results and no real products behind them. The value is in the direction, the interaction and the finish, not in a claim about a business outcome.
